One image that sums up Saturday 21 November 2026: Russia's biggest strikes of the year on Ukraine, with missiles coming down in Poland; Trump, Xi and Putin meeting at a trilateral summit in Shenzhen; the UN Court holding Myanmar responsible for genocide against the Rohingya; the AI stock rout that put the S&P 500 into correction; and a cancer-pill trial in which tumours vanished in 1 in 12 patients. The program ships the finished front page as entry.png and copies it to the output directory unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
